One poster for one day of world news: Saturday 21 November 2026, told in six drawn tiles and a
short ticker. Each tile is a story that broke that day — Gaza, Riyadh, the Gulf of Finland,
Bangladesh, the EU–Indonesia trade deal and BepiColombo reaching Mercury — and every mark in the
picture is drawn for this repository, with the sources listed in `SOURCES.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the committed `entry.png` (1024×1024, ~100 KB) to `/output/entry.png` in the
grader's sandbox; it needs Node 22 and nothing else, and uses no network.
